# Lunite RSPS Bot

Welcome to the **Lunite RSPS Bot**.

This bot is installed as a plugin inside the Lunite Client. Follow the
steps below carefully to make sure everything is installed correctly.

## Requirements

Before you begin, make sure you have:

-   **Lunite Client**
-   **MRWK.zip**
-   **WinRAR** or another program that can open `.jar` files

## Installation

### Step 1 --- Extract MRWK.zip

Extract `MRWK.zip`.

After extracting the ZIP file, you should have a folder named:

``` text
MRWK
```

Do not rename this folder.

### Step 2 --- Open Lunite-Client-Hd.jar

Open `Lunite-Client-Hd.jar` using **WinRAR**.

You do **not** need to extract the `.jar` file. Simply open it directly
with WinRAR.

### Step 3 --- Navigate to the Plugins folder

Inside `Lunite-Client-Hd.jar`, navigate to:

``` text
net\runelite\client\plugins
```

### Step 4 --- Add MRWK

Drag the complete `MRWK` folder into:

``` text
net\runelite\client\plugins
```

Your folder structure should look like this:

``` text
Lunite-Client-Hd.jar
└── net
    └── runelite
        └── client
            └── plugins
                └── MRWK
```

**Important:** Make sure the complete `MRWK` folder is placed directly
inside the `plugins` folder.

## Starting the Client

Once you have added the files, start the **Lunite Client** normally.

If the installation was successful, you should see the following new
plugins:

-   **MR - Attacker**
-   **MR - Boss**
-   **MR - Consumer**
-   **MR - Core**

If these plugins are visible in the client, the installation was
successful.

## Plugins

### MR - Core

The **Core** plugin provides the foundation for the other MR plugins and
handles the core functionality required by the bot.

### MR - Attacker

The **Attacker** plugin handles the bot's attack and combat-related
functionality.

### MR - Boss

The **Boss** plugin provides functionality related to bossing and the
corresponding bot features.

### MR - Consumer

The **Consumer** plugin handles automatically consuming or using
required items.

> Available features and settings may vary depending on the version of
> the bot.

## Troubleshooting

If the plugins do not appear, check the following:

1.  Make sure `MRWK.zip` was extracted completely.
2.  Make sure the extracted folder is named **MRWK**.
3.  Make sure you added the **entire MRWK folder**.
4.  Make sure `MRWK` is located inside: `net\runelite\client\plugins`
5.  Fully restart the Lunite Client after installing the plugin.
6.  Make sure you are using the correct `Lunite-Client-Hd.jar`.

If the plugins are still not showing, double-check that your folder
structure matches the example above.
